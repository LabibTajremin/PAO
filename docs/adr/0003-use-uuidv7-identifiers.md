# ADR-0003: Use UUIDv7 identifiers

- Status: Accepted
- Date: 2026-10-09
- Source: 04-decisions.md E3

## Context

IDs are exposed in URLs and must not leak counts or be guessable, while staying index-friendly.

## Decision

Every entity uses a UUIDv7 primary key generated by the injectable `idgen` package. Human-facing booking numbers come from a separate sequence.

## Consequences

Time-ordered inserts keep B-tree indexes compact; cursor pagination can order by ID.
