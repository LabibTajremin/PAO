# docs/adr

Architecture decision records, one per significant decision. Copy
[`0000-template.md`](0000-template.md) to add one; never edit an accepted ADR silently —
supersede it with a new one.

ADRs 0010–0025 record the product defaults from `docs/build/04-decisions.md`
(D1–D16). Those marked *Proposed — needs owner review* are waiting for a decision.
