# ADR-0024: Do not build Phase 2 or Later features

- Status: Accepted (default — owner may revise)
- Date: 2026-10-09
- Source: PRD §13; docs/build/04-decisions.md D15

## Context

The PRD leaves this question open (§13). The build needs a default to stay autonomous (D15).

## Decision

Out of scope: C-16–C-22, P-14–P-16, A-11–A-12 and the Figma "Phase 2" screens in section 13. No stubs are built for them.

## Consequences

The owner may revise this default; changing it later means a new ADR that supersedes this one, not a silent edit.
