# design

Brand and illustration sources for PAO. Apps and the admin panel copy what they need from here;
change things here first.

- `brand/`: the PAO logo. `svg/` sources, `png/` exports, `app-icons/` for iOS (light, dark,
  tinted), Android (adaptive foreground, monochrome) and web, `receipt/watermark.svg`.
  Use the `-dark` / `-ivory` (inverse) files on dark backgrounds.
- `illustrations/`: seed artwork for the admin-managed slots. Sizes and rules:
  `docs/build/06-update-2026-11.md` §5.
- `icons/`: the service icon library (24 × 24, single colour).
- `reference/`: what the owner gave us: colour palette, sign-in illustration demo, logo
  reference sheet and the 2026-11 update note.

Colours: logo ink `#0B0B0C`, ivory `#F5F2EB`; app palette in `06-update-2026-11.md` §2.
